# Leer y trazar

No hay que implementar nada ni correr código. Lee `agrupar_por_ventana.py` y traza estas llamadas a mano:

```python
agrupar_por_ventana([1, 3, 10, 11, 25], 5)
agrupar_por_ventana([1, 3, 10, 11, 25], 3)
```

Que puedas seguir el bucle paso a paso y escribir el valor que devuelve la función.

Di en voz alta cómo cambian `actual` y `grupos` en cada iteración, y cierra con el resultado.
